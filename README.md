# E-commerce Sales Analysis using MySQL



## Project Overview



This project analyzes e-commerce data using MySQL to explore customer activity, orders, product sales, and category-wise revenue.



## Database Tables



- "customers" — Customer information

- "orders" — Order details and recorded amounts

- "order\_items" — Products and quantities in each order

- "products" — Product names, prices, and categories

- "categories" — Product category information



## Key Findings



- Total customers: 9

- Total orders: 7

- Total sales recorded in the orders table: ₹135,700

- Top-selling product by quantity: Mouse (3 units)

- Electronics category sales: ₹122,000

- Accessories category sales: ₹6,100

- Audio category sales: ₹3,500



## SQL Concepts Used



- SELECT and aggregate functions

- SUM and COUNT

- INNER JOIN

- GROUP BY and ORDER BY

- LIMIT



## Tools



- MySQL

- MySQL Workbench



## Project Goal



To practice SQL-based data analysis and demonstrate how relational databases can be used to extract useful business insights.
